About the game

7 + 8 = 16. True or false? A sum appears with an answer. Tap TRUE if it is correct, FALSE if it is not. The sums get bigger and the clock gets shorter the longer you last.

  • One-tap play, no typing
  • Addition, subtraction and times tables
  • Works offline, small download, no sign-up
